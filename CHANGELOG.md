# v1.6.0-beta5

## New features

- Add community themes that can be imported from a local file or a direct link.
- Review theme permissions before installation, with each capability denied by default.
- Apply installed themes across Still, Today, and supported widgets, with light, dark, or system appearance choices.
- Add optional update checks for linked themes, with updates staged for review before activation.

## Tweaks

- Add seasonal availability, local persistence, and management controls for installed themes.
- Add the Theme Compose 1 package format and authoring documentation.
- Improve theme previews and theme-aware widget rendering.

## Fixes

- Keep theme packages, consent, and source links in private local storage with atomic persistence.
- Prevent denied theme capabilities from being queried and prevent unreviewed updates from activating automatically.
- Refresh widgets and active theme rendering after theme changes.
