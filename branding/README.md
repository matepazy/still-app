# Still logo system

Still uses one responsive symbol: a soft monoline `S` held between two mint points. The path is deliberately simple so it stays legible at launcher size, in the app chrome, and in larger brand placements.

## Assets

| Asset | Use |
| --- | --- |
| `still_icon_master.svg` | Primary app icon, store listings, README and dark tile contexts |
| `still_icon_foreground.svg` | Android adaptive-icon foreground layer |
| `still_icon_monochrome.svg` | Android 13+ themed icon layer |
| `still_mark.svg` | Transparent symbol on dark surfaces |
| `still_mark_ink.svg` | Transparent symbol on light surfaces |
| `still_lockup.svg` | Horizontal symbol + “Still” on light surfaces |
| `still_lockup_inverse.svg` | Horizontal symbol + “Still” on dark surfaces |
| `still_stacked.svg` | Vertical lockup for splash, onboarding, and narrow placements |
| `still_wordmark.svg` / `still_wordmark_inverse.svg` | Wordmark-only fallback when the symbol is already present |
| `still_brand_mark.svg` | Backwards-compatible alias of `still_lockup.svg` |

## Core colors

- Deep green-black: `#111713`
- Paper: `#E9F5EC`
- Mint: `#9FE3B2`
- Light-surface ink: `#172019`
- Light-surface green: `#27683C`

Keep the symbol’s two endpoint dots. They are the distinctive detail and are not decorative bullets. Do not add shadows, gradients, outlines, or extra rounded containers around the lockups.
